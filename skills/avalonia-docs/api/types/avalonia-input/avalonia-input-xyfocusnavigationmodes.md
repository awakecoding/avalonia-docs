# Avalonia.Input.XYFocusNavigationModes

Specifies the 2D directional navigation behavior when using different key devices.

## Metadata

- Kind: Enum
- Namespace: [Avalonia.Input](../../namespaces/avalonia-input.md)
- Assemblies: Avalonia.Base

## Syntax

```csharp
[Flags] public enum XYFocusNavigationModes
```

## Fields

| Member | Summary |
| --- | --- |
| `XYFocusNavigationModes.Disabled` | Any key device XY navigation is disabled. |
| `XYFocusNavigationModes.Enabled` | All key device XY navigation is disabled. |
| `XYFocusNavigationModes.Gamepad` | Gamepad controller DPad keys can be used for 2D directional navigation. |
| `XYFocusNavigationModes.Keyboard` | Keyboard arrow keys can be used for 2D directional navigation. |
| `XYFocusNavigationModes.Remote` | Remote controller DPad keys can be used for 2D directional navigation. |
