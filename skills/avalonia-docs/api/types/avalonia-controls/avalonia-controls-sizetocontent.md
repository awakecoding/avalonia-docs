# Avalonia.Controls.SizeToContent

Determines how a will size itself to fit its content.

## Metadata

- Kind: Enum
- Namespace: [Avalonia.Controls](../../namespaces/avalonia-controls.md)
- Assemblies: Avalonia.Controls

## Syntax

```csharp
[Flags] public enum SizeToContent
```

## Fields

| Member | Summary |
| --- | --- |
| `SizeToContent.Height` | The window will size itself vertically to fit its content. |
| `SizeToContent.Manual` | The window will not automatically size itself to fit its content. |
| `SizeToContent.Width` | The window will size itself horizontally to fit its content. |
| `SizeToContent.WidthAndHeight` | The window will size itself horizontally and vertically to fit its content. |
