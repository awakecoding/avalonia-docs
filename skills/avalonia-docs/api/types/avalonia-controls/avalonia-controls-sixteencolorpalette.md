# Avalonia.Controls.SixteenColorPalette

Implements the standard sixteen color palette from the HTML 4.01 specification.

## Metadata

- Kind: Class
- Namespace: [Avalonia.Controls](../../namespaces/avalonia-controls.md)
- Assemblies: Avalonia.Controls.ColorPicker

## Inheritance

- `System.Object`

## Syntax

```csharp
public class SixteenColorPalette : IColorPalette
```

## Properties

| Member | Summary |
| --- | --- |
| `SixteenColorPalette.ColorCount` | Gets the total number of colors in this palette. A color is not necessarily a single value and may be composed of several shades. |
| `SixteenColorPalette.ShadeCount` | Gets the total number of shades for each color in this palette. Shades are usually a variation of the color lightening or darkening it. |

## Methods

| Member | Summary |
| --- | --- |
| `SixteenColorPalette.GetColor(int, int)` | Gets a color in the palette by index. |
