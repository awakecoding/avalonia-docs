# Avalonia.Controls.SplitViewDisplayMode

Defines constants for how the SplitView Pane should display

## Metadata

- Kind: Enum
- Namespace: [Avalonia.Controls](../../namespaces/avalonia-controls.md)
- Assemblies: Avalonia.Controls

## Syntax

```csharp
public enum SplitViewDisplayMode
```

## Fields

| Member | Summary |
| --- | --- |
| `SplitViewDisplayMode.CompactInline` | Pane is displayed next to content. When collapsed, pane is still visible according to CompactPaneLength. Pane does not auto collapse when tapped outside |
| `SplitViewDisplayMode.CompactOverlay` | Pane is displayed above content. When collapsed, pane is still visible according to CompactPaneLength. Pane collapses when tapped outside |
| `SplitViewDisplayMode.Inline` | Pane is displayed next to content, and does not auto collapse when tapped outside |
| `SplitViewDisplayMode.Overlay` | Pane is displayed above content. Pane collapses when tapped outside |
