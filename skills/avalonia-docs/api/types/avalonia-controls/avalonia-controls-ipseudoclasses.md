# Avalonia.Controls.IPseudoClasses

Exposes an interface for setting pseudoclasses on a collection.

## Metadata

- Kind: Interface
- Namespace: [Avalonia.Controls](../../namespaces/avalonia-controls.md)
- Assemblies: Avalonia.Base

## Syntax

```csharp
public interface IPseudoClasses
```

## Methods

| Member | Summary |
| --- | --- |
| `IPseudoClasses.Add(string)` | Adds a pseudoclass to the collection. |
| `IPseudoClasses.Contains(string)` | Returns whether a pseudoclass is present in the collection. |
| `IPseudoClasses.Remove(string)` | Removes a pseudoclass from the collection. |
