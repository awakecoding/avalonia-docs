# Avalonia.Controls.ColorComponent

Defines a specific component within a color model.

## Metadata

- Kind: Enum
- Namespace: [Avalonia.Controls](../../namespaces/avalonia-controls.md)
- Assemblies: Avalonia.Controls.ColorPicker

## Syntax

```csharp
public enum ColorComponent
```

## Fields

| Member | Summary |
| --- | --- |
| `ColorComponent.Alpha` | Represents the alpha component. |
| `ColorComponent.Component1` | Represents the first color component which is Red when RGB or Hue when HSV. |
| `ColorComponent.Component2` | Represents the second color component which is Green when RGB or Saturation when HSV. |
| `ColorComponent.Component3` | Represents the third color component which is Blue when RGB or Value when HSV. |
