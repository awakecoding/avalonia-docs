# Avalonia.Controls.TabPlacement

Specifies the position of the tab strip within a layout.

## Metadata

- Kind: Enum
- Namespace: [Avalonia.Controls](../../namespaces/avalonia-controls.md)
- Assemblies: Avalonia.Controls

## Syntax

```csharp
public enum TabPlacement
```

## Fields

| Member | Summary |
| --- | --- |
| `TabPlacement.Auto` | Automatically determines the tab placement based on the target platform. Resolves to on iOS and Android, and on all other platforms. |
| `TabPlacement.Left` | Displays tabs along the left side of the content area. |
| `TabPlacement.Right` | Displays tabs along the right side of the content area. |
