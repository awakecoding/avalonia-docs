# Avalonia.Controls.DrawerLayoutBehavior

Defines the layout behavior of the drawer page.

## Metadata

- Kind: Enum
- Namespace: [Avalonia.Controls](../../namespaces/avalonia-controls.md)
- Assemblies: Avalonia.Controls

## Syntax

```csharp
public enum DrawerLayoutBehavior
```

## Fields

| Member | Summary |
| --- | --- |
| `DrawerLayoutBehavior.CompactInline` | A narrow rail strip is always visible; opening expands and pushes the detail content aside. |
| `DrawerLayoutBehavior.CompactOverlay` | A narrow rail strip is always visible; opening expands as an overlay over the detail content. |
| `DrawerLayoutBehavior.Overlay` | The drawer overlays the detail content when open. |
| `DrawerLayoutBehavior.Split` | The drawer and detail content are shown side by side when open. |
