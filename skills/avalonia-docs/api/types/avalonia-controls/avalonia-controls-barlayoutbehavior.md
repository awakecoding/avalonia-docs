# Avalonia.Controls.BarLayoutBehavior

Controls how the navigation bar interacts with the page content area.

## Metadata

- Kind: Enum
- Namespace: [Avalonia.Controls](../../namespaces/avalonia-controls.md)
- Assemblies: Avalonia.Controls

## Syntax

```csharp
public enum BarLayoutBehavior
```

## Fields

| Member | Summary |
| --- | --- |
| `BarLayoutBehavior.Inset` | Default. The navigation bar takes up layout space; page content is laid out below it. |
| `BarLayoutBehavior.Overlay` | The navigation bar floats above the page content. Content extends behind the bar. |
