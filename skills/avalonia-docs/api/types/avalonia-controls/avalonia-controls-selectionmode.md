# Avalonia.Controls.SelectionMode

Defines the selection mode for a control which can select multiple items.

## Metadata

- Kind: Enum
- Namespace: [Avalonia.Controls](../../namespaces/avalonia-controls.md)
- Assemblies: Avalonia.Controls

## Syntax

```csharp
[Flags] public enum SelectionMode
```

## Fields

| Member | Summary |
| --- | --- |
| `SelectionMode.AlwaysSelected` | An item will always be selected as long as there are items to select. |
| `SelectionMode.Multiple` | Multiple items can be selected. |
| `SelectionMode.Single` | One item can be selected. |
| `SelectionMode.Toggle` | Item selection can be toggled by tapping/spacebar. |
