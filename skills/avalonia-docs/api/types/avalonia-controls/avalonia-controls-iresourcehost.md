# Avalonia.Controls.IResourceHost

Represents an element which hosts resources.

## Metadata

- Kind: Interface
- Namespace: [Avalonia.Controls](../../namespaces/avalonia-controls.md)
- Assemblies: Avalonia.Base

## Syntax

```csharp
public interface IResourceHost : IResourceNode
```

## Methods

| Member | Summary |
| --- | --- |
| `IResourceHost.NotifyHostedResourcesChanged(ResourcesChangedEventArgs)` | Notifies the resource host that one or more of its hosted resources has changed. |

## Events

| Member | Summary |
| --- | --- |
| `IResourceHost.ResourcesChanged` | Raised when the resources change on the element or an ancestor of the element. |
