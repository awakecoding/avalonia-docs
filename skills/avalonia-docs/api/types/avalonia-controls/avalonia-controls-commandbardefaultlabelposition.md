# Avalonia.Controls.CommandBarDefaultLabelPosition

Defines how labels are positioned for command bar buttons.

- Kind: Enum

## Fields

| Member | Summary |
| --- | --- |
| `CommandBarDefaultLabelPosition.Bottom` | Label is displayed below the icon. |
| `CommandBarDefaultLabelPosition.Collapsed` | No label is visible (icon only). |
| `CommandBarDefaultLabelPosition.Right` | Label is displayed to the right of the icon. |
