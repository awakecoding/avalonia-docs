# Avalonia.Controls.Primitives.ScrollBarVisibility

Specifies the visibility of a for scrollable content.

## Metadata

- Kind: Enum
- Namespace: [Avalonia.Controls.Primitives](../../namespaces/avalonia-controls-primitives.md)
- Assemblies: Avalonia.Controls

## Syntax

```csharp
public enum ScrollBarVisibility
```

## Fields

| Member | Summary |
| --- | --- |
| `ScrollBarVisibility.Auto` | The scrollbar should be visible only if there is more content than fits in the viewport. |
| `ScrollBarVisibility.Disabled` | No scrollbars and no scrolling in this dimension. |
| `ScrollBarVisibility.Hidden` | The scrollbar should never be visible. No space should ever be reserved for the scrollbar. |
| `ScrollBarVisibility.Visible` | The scrollbar should always be visible. Space should always be reserved for the scrollbar. |
