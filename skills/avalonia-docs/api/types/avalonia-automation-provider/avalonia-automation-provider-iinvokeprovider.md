# Avalonia.Automation.Provider.IInvokeProvider

Exposes methods and properties to support UI Automation client access to controls that initiate or perform a single, unambiguous action and do not maintain state when activated.

## Metadata

- Kind: Interface
- Namespace: [Avalonia.Automation.Provider](../../namespaces/avalonia-automation-provider.md)
- Assemblies: Avalonia.Controls

## Syntax

```csharp
public interface IInvokeProvider
```

## Methods

| Member | Summary |
| --- | --- |
| `IInvokeProvider.Invoke()` | Sends a request to activate a control and initiate its single, unambiguous action. |
