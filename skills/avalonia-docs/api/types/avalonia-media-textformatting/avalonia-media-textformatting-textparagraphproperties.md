# Avalonia.Media.TextFormatting.TextParagraphProperties

Provides a set of properties that are used during the paragraph layout.

## Metadata

- Kind: Class
- Namespace: [Avalonia.Media.TextFormatting](../../namespaces/avalonia-media-textformatting.md)
- Assemblies: Avalonia.Base

## Inheritance

- `System.Object`

## Syntax

```csharp
public abstract class TextParagraphProperties
```

## Properties

| Member | Summary |
| --- | --- |
| `TextParagraphProperties.AlwaysCollapsible` | Gets a value that indicates whether a formatted line can always be collapsed. |
| `TextParagraphProperties.DefaultIncrementalTab` | Gets the default incremental tab width. |
| `TextParagraphProperties.DefaultTextRunProperties` | Gets the default text run properties, such as typeface or foreground brush. |
| `TextParagraphProperties.FirstLineInParagraph` | Gets a value that indicates whether the text run is the first line of the paragraph. |
| `TextParagraphProperties.FlowDirection` | Gets a value that specifies whether the primary text advance direction shall be left-to-right, or right-to-left. |
| `TextParagraphProperties.Indent` | Gets the amount of line indentation. |
| `TextParagraphProperties.LetterSpacing` | Gets the amount of letter spacing. |
| `TextParagraphProperties.LineHeight` | Gets the height of a line of text. |
| `TextParagraphProperties.ParagraphIndent` | Gets the paragraph indentation. |
| `TextParagraphProperties.TextAlignment` | Gets a value that describes how an inline content of a block is aligned. |
| `TextParagraphProperties.TextDecorations` | Gets the collection of TextDecoration objects. |
| `TextParagraphProperties.TextWrapping` | Gets a value that controls whether text wraps when it reaches the flow edge of its containing block box. |
