# Avalonia.Automation.AccessibilityView

Declares how a control should included in different views of the automation tree.

## Metadata

- Kind: Enum
- Namespace: [Avalonia.Automation](../../namespaces/avalonia-automation.md)
- Assemblies: Avalonia.Controls

## Syntax

```csharp
public enum AccessibilityView
```

## Fields

| Member | Summary |
| --- | --- |
| `AccessibilityView.Content` | The control is included in the Content view of the automation tree. |
| `AccessibilityView.Control` | The control is included in the Control view of the automation tree. |
| `AccessibilityView.Default` | The control's view is defined by its automation peer. |
| `AccessibilityView.Raw` | The control is included in the Raw view of the automation tree. |
