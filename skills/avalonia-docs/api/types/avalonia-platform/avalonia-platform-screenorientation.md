# Avalonia.Platform.ScreenOrientation

Describes the orientation of a screen.

## Metadata

- Kind: Enum
- Namespace: [Avalonia.Platform](../../namespaces/avalonia-platform.md)
- Assemblies: Avalonia.Controls

## Syntax

```csharp
public enum ScreenOrientation
```

## Fields

| Member | Summary |
| --- | --- |
| `ScreenOrientation.Landscape` | Specifies that the monitor is oriented in landscape mode where the width of the screen viewing area is greater than the height. |
| `ScreenOrientation.LandscapeFlipped` | Specifies that the monitor rotated another 90 degrees in the clockwise direction (to equal 180 degrees) to orient the screen in landscape mode where the width of the screen viewing area is greater than the height. This landscape mode is flipped 180 degrees from the Landscape mode. |
| `ScreenOrientation.None` | No screen orientation is specified. |
| `ScreenOrientation.Portrait` | Specifies that the monitor rotated 90 degrees in the clockwise direction to orient the screen in portrait mode where the height of the screen viewing area is greater than the width. |
| `ScreenOrientation.PortraitFlipped` | Specifies that the monitor rotated another 90 degrees in the clockwise direction (to equal 270 degrees) to orient the screen in portrait mode where the height of the screen viewing area is greater than the width. This portrait mode is flipped 180 degrees from the Portrait mode. |
