# Avalonia.Controls.Notifications.INotificationManager

Represents a notification manager that can be used to show notifications in a window or using the host operating system.

## Metadata

- Kind: Interface
- Namespace: [Avalonia.Controls.Notifications](../../namespaces/avalonia-controls-notifications.md)
- Assemblies: Avalonia.Controls

## Syntax

```csharp
public interface INotificationManager
```

## Methods

| Member | Summary |
| --- | --- |
| `INotificationManager.Close(INotification)` | Closes a notification. |
| `INotificationManager.CloseAll()` | Closes all notifications. |
| `INotificationManager.Show(INotification)` | Show a notification. |
