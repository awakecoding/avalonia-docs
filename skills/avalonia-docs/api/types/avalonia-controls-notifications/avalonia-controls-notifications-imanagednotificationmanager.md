# Avalonia.Controls.Notifications.IManagedNotificationManager

Represents a notification manager that can show arbitrary content. Managed notification managers can show any content.

## Metadata

- Kind: Interface
- Namespace: [Avalonia.Controls.Notifications](../../namespaces/avalonia-controls-notifications.md)
- Assemblies: Avalonia.Controls

## Syntax

```csharp
public interface IManagedNotificationManager : INotificationManager
```

## Methods

| Member | Summary |
| --- | --- |
| `IManagedNotificationManager.Close(object)` | Closes a notification. |
| `IManagedNotificationManager.Show(object)` | Shows a notification. |
