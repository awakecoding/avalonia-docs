# Avalonia.Layout.VerticalAlignment

Defines how a control aligns itself vertically in its parent control.

## Metadata

- Kind: Enum
- Namespace: [Avalonia.Layout](../../namespaces/avalonia-layout.md)
- Assemblies: Avalonia.Base

## Syntax

```csharp
public enum VerticalAlignment
```

## Fields

| Member | Summary |
| --- | --- |
| `VerticalAlignment.Bottom` | The control aligns itself to the bottom of the parent control. |
| `VerticalAlignment.Center` | The control centers itself within the parent control. |
| `VerticalAlignment.Stretch` | The control stretches to fill the height of the parent control. |
| `VerticalAlignment.Top` | The control aligns itself to the top of the parent control. |
