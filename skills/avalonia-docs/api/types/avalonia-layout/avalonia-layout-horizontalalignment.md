# Avalonia.Layout.HorizontalAlignment

Defines how a control aligns itself horizontally in its parent control.

## Metadata

- Kind: Enum
- Namespace: [Avalonia.Layout](../../namespaces/avalonia-layout.md)
- Assemblies: Avalonia.Base

## Syntax

```csharp
public enum HorizontalAlignment
```

## Fields

| Member | Summary |
| --- | --- |
| `HorizontalAlignment.Center` | The control centers itself in the parent control. |
| `HorizontalAlignment.Left` | The control aligns itself to the left of the parent control. |
| `HorizontalAlignment.Right` | The control aligns itself to the right of the parent control. |
| `HorizontalAlignment.Stretch` | The control stretches to fill the width of the parent control. |
