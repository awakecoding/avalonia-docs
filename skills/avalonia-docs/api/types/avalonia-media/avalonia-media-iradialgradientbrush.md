# Avalonia.Media.IRadialGradientBrush

Paints an area with a radial gradient.

## Metadata

- Kind: Interface
- Namespace: [Avalonia.Media](../../namespaces/avalonia-media.md)
- Assemblies: Avalonia.Base

## Syntax

```csharp
public interface IRadialGradientBrush : IGradientBrush, IBrush
```

## Properties

| Member | Summary |
| --- | --- |
| `IRadialGradientBrush.Center` | Gets the start point for the gradient. |
| `IRadialGradientBrush.GradientOrigin` | Gets the location of the two-dimensional focal point that defines the beginning of the gradient. |
| `IRadialGradientBrush.RadiusX` | Gets the horizontal radius of the outermost circle of the radial gradient. |
| `IRadialGradientBrush.RadiusY` | Gets the vertical radius of the outermost circle of the radial gradient. |
