## Fields

| Member | Summary |
| --- | --- |
| `TextAlignment.Center` | The text is centered. |
| `TextAlignment.DetectFromContent` | Text alignment is inferred from the text content. |
| `TextAlignment.End` | The end of the text is aligned to the edge of the available space. |
| `TextAlignment.Justify` | Text is justified within the available space. |
| `TextAlignment.Left` | The text is left-aligned. |
| `TextAlignment.Right` | The text is right-aligned. |
| `TextAlignment.Start` | The beginning of the text is aligned to the edge of the available space. |
