## Fields

| Member | Summary |
| --- | --- |
| `TileMode.FlipX` | The content will be repeated horizontally, with alternate tiles mirrored. |
| `TileMode.FlipXY` | The content will be repeated horizontally and vertically, with alternate tiles mirrored. |
| `TileMode.FlipY` | The content will be repeated vertically, with alternate tiles mirrored. |
