# Avalonia.Media.ITileBrush

A brush which displays a repeating image.

## Metadata

- Kind: Interface
- Namespace: [Avalonia.Media](../../namespaces/avalonia-media.md)
- Assemblies: Avalonia.Base

## Syntax

```csharp
public interface ITileBrush : IBrush
```

## Properties

| Member | Summary |
| --- | --- |
| `ITileBrush.AlignmentX` | Gets the horizontal alignment of a tile in the destination. |
| `ITileBrush.AlignmentY` | Gets the horizontal alignment of a tile in the destination. |
| `ITileBrush.DestinationRect` | Gets the rectangle on the destination in which to paint a tile. |
| `ITileBrush.SourceRect` | Gets the rectangle of the source image that will be displayed. |
| `ITileBrush.Stretch` | Gets a value indicating how the source rectangle will be stretched to fill the destination rect. |
