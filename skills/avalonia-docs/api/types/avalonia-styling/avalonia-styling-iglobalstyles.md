# Avalonia.Styling.IGlobalStyles

Defines the style host that provides styles global to the application.

## Metadata

- Kind: Interface
- Namespace: [Avalonia.Styling](../../namespaces/avalonia-styling.md)
- Assemblies: Avalonia.Base

## Syntax

```csharp
public interface IGlobalStyles : IStyleHost
```

## Events

| Member | Summary |
| --- | --- |
| `IGlobalStyles.GlobalStylesAdded` | Raised when styles are added to or a nested styles collection. |
| `IGlobalStyles.GlobalStylesRemoved` | Raised when styles are removed from or a nested styles collection. |
