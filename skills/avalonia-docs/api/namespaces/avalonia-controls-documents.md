# Avalonia.Controls.Documents

## Types

- [Avalonia.Controls.Documents.Bold](../types/avalonia-controls-documents/avalonia-controls-documents-bold.md) - Bold element - markup helper for indicating bolded content. Equivalent to a Span with FontWeight property set to FontWeights.Bold. Can contain other inline elements.
- [Avalonia.Controls.Documents.Inline](../types/avalonia-controls-documents/avalonia-controls-documents-inline.md) - Inline element.
- [Avalonia.Controls.Documents.InlineCollection](../types/avalonia-controls-documents/avalonia-controls-documents-inlinecollection.md) - A collection of s.
- [Avalonia.Controls.Documents.InlineUIContainer](../types/avalonia-controls-documents/avalonia-controls-documents-inlineuicontainer.md) - InlineUIContainer - a wrapper for embedded UIElements in text flow content inline collections
- [Avalonia.Controls.Documents.Italic](../types/avalonia-controls-documents/avalonia-controls-documents-italic.md) - Italic element - markup helper for indicating italicized content. Equivalent to a Span with FontStyle property set to FontStyles.Italic. Can contain other inline elements.
- [Avalonia.Controls.Documents.LineBreak](../types/avalonia-controls-documents/avalonia-controls-documents-linebreak.md) - LineBreak element that forces a line breaking.
- [Avalonia.Controls.Documents.Run](../types/avalonia-controls-documents/avalonia-controls-documents-run.md) - A terminal element in text flow hierarchy - contains a uniformatted run of unicode characters
- [Avalonia.Controls.Documents.Span](../types/avalonia-controls-documents/avalonia-controls-documents-span.md) - Span element used for grouping other Inline elements.
- [Avalonia.Controls.Documents.TextElement](../types/avalonia-controls-documents/avalonia-controls-documents-textelement.md) - TextElement is an base class for content in text based controls. TextElements span other content, applying property values or providing structural information.
- [Avalonia.Controls.Documents.Underline](../types/avalonia-controls-documents/avalonia-controls-documents-underline.md) - Underline element - markup helper for indicating superscript content. Equivalent to a Span with TextDecorations property set to TextDecorations.Underlined. Can contain other inline elements.
