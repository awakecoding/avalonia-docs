# Implementation Guides

These guides show you how to use various implementation architectures and techniques with _Avalonia UI_.

- [How To Use the MVVM Pattern](how-to-use-the-mvvm-pattern.md) — A guide to developing apps using the Model, View, ViewModel architecture.
- [How To Implement Dependency Injection](how-to-implement-dependency-injection.md) — A guide to understanding how to use Dependency Injection (DI) in your apps.
- [Developer Tools](developer-tools.md) — Learn how to debug your applications visuals.
- [How To Log Errors and Warnings](logging-errors-and-warnings.md) — This guide shows you how to can log warnings and errors in Avalonia.
- [How To Use Live Preview](ide-support.md) — This guide will show you how to use the live preview feature of the Avalonia UI IDE extensions
- [How To Use Design-time Data](how-to-use-design-time-data.md) — Learn how to use design-time data to avoid having to build your entire app.
- [Localizing using ResX](localizing.md) — Learn how to use ResX to localize your app.
