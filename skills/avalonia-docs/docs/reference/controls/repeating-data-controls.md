# Repeating Data Controls

These controls display repeating data, in either a tabular or list format:

<table><thead><tr><th width="196">Control</th><th>Description</th></tr></thead><tbody><tr><td><a href="datagrid/README.md">DataGrid</a></td><td>Displays data in a customizable grid.</td></tr><tr><td><a href="itemscontrol.md">ItemsControl</a></td><td>Displays a collection of items from a bound data source.</td></tr><tr><td><a href="itemsrepeater.md">ItemsRepeater</a></td><td>Displays repeating data from a bound data source. It has both a layout template and a data template. </td></tr><tr><td><a href="listbox.md">ListBox</a></td><td>A control with items that can be selected.</td></tr><tr><td><a href="combobox.md">ComboBox</a></td><td>A control with a drop-down list with items that can be selected.</td></tr></tbody></table>
